# אתר שופטי השחייה בישראל: פרויקט Next.js

המחסנית: Next.js 14 (App Router, TypeScript), Prisma + PostgreSQL, NextAuth (Credentials), פריסה ל-Vercel.

## איך ההרשמה וההרשאות עובדות

**הרשמה עצמית + אישור אדמין**
1. שופט/ת נכנס/ת ל-`/register`, ממלא/ת פרטים ובוחר/ת סיסמה. נוצר חשבון במצב `PENDING`.
2. עד לאישור אי אפשר להתחבר (מוצגת הודעה "ממתין לאישור").
3. האדמין נכנס ל-`/admin`, רואה את הבקשות הממתינות ומאשר/ת או דוחה.
4. אדמין יכול גם ליצור חשבון ישירות (מקבל סיסמה זמנית להעברה לשופט/ת), לאפס סיסמה, להשבית חשבון ולהפוך משתמש/ת לאדמין.

**שלוש רמות הרשאה (נאכפות בשרת, ראו `lib/authz.ts` ו-`actions/`)**
- **אדמין:** `User.isAdmin`. ניהול שופטים, תחרויות, תבניות מפה, שיוך שופטים ראשיים, דוח כללי ויומן פעולות.
- **שופט/ת ראשי/ת:** ספציפי לתחרות, נקבע רק דרך טבלת `CompetitionHeadJudge`. אין תפקיד גלובלי. מקבל/ת גישה לעמוד "שופטים ראשיים", לשיבוץ במפה, להערות, ל-walk-in ולדוח הרישום **של אותה תחרות בלבד**.
- **שופט/ת רגיל/ה:** כל השאר. רישום עצמי, עריכת פרטי הקשר של עצמו/ה, צפייה בתחרויות.

מספרי טלפון של שופטים אחרים נשלחים ללקוח רק למנהל/ת ולשופט/ת הראשי/ת של התחרות הרלוונטית.

## הקמה: שלב אחר שלב

### 1. מסד נתונים (חינם)
צרו פרויקט ב-[Neon](https://neon.tech) או [Supabase](https://supabase.com) והעתיקו את מחרוזת החיבור ל-Postgres.

### 2. הרצה מקומית ראשונה (יוצרת טבלאות וחשבון אדמין)
```bash
npm install
cp .env.example .env        # ערכו: DATABASE_URL, NEXTAUTH_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD
npm run db:push             # יוצר את הטבלאות במסד
npm run db:seed             # יוצר חשבון אדמין ראשוני + תבנית מפת בריכה ברירת מחדל
npm run dev                 # http://localhost:3000
```
ליצירת `NEXTAUTH_SECRET`: `openssl rand -base64 32`

### 3. פריסה ל-Vercel
1. העלו את הפרויקט ל-GitHub.
2. ב-[Vercel](https://vercel.com): New Project ← בחרו את המאגר.
3. Environment Variables: `DATABASE_URL`, `NEXTAUTH_SECRET`, `NEXTAUTH_URL` (הכתובת הסופית של האתר, למשל `https://your-site.vercel.app`).
4. Deploy. את `db:push` ו-`db:seed` מריצים פעם אחת מהמחשב (שלב 2) מול אותו מסד.

### 4. אחרי הפריסה
1. היכנסו עם ADMIN_EMAIL / ADMIN_PASSWORD.
2. `/admin/layouts`: ודאו שתבנית המפה נכונה (או צרו תבנית לבריכה אחרת).
3. `/admin/competitions`: צרו תחרויות, הגדירו הצגות ושייכו שופטים ראשיים.
4. שלחו לשופטים את הקישור. הם נרשמים ב-`/register` ואתם מאשרים ב-`/admin`.

## מבנה הפרויקט
```
prisma/schema.prisma     מודל הנתונים
prisma/seed.ts           אדמין ראשוני + תבנית ברירת מחדל
lib/authz.ts             כל בדיקות ההרשאה (מקור האמת)
lib/auth.ts              הגדרות NextAuth
actions/*.ts             Server Actions, כל אחת בודקת הרשאה בעצמה
app/(app)/...            העמודים אחרי התחברות
app/api/export/...       ייצוא Excel (עם בדיקת הרשאה)
components/PoolMap.tsx   מפת הבריכה (SVG), דינמית לפי PoolLayout
```

## מה חשוב לדעת
- **הקוד נכתב ולא הורץ.** בסביבה שבה נכתב לא הייתה גישה לרשת ולכן לא בוצעו `npm install`, בנייה או הרצה. נבדק שהקוד תקין תחבירית ושהמודולים הפנימיים מתחברים זה לזה, אך צפויים תיקונים קטנים בהרצה הראשונה.
- ב-`next.config.mjs` בדיקת טיפוסים ו-lint בזמן ה-build כבויות, כדי שפריסה ראשונה לא תיכשל על שגיאת טיפוס קטנה. הריצו `npm run typecheck`, תקנו, והסירו את השורות.
- **לא כלול:** שחזור סיסמה במייל (כרגע אדמין מאפס סיסמה ומעביר סיסמה זמנית), אימות כתובת מייל, הגבלת ניסיונות התחברות (rate limiting). לפני שימוש רחב מומלץ להוסיף אותם, למשל Cloudflare Turnstile בהרשמה ו-Upstash Ratelimit בהתחברות.
- מספרי טלפון ופרטים אישיים של שופטים הם מידע אישי. מומלץ לוודא עמידה בדרישות הפרטיות החלות על הארגון ולהפעיל גיבויים אוטומטיים במסד.
- מצב כהה נתמך אוטומטית לפי הגדרות המכשיר.
